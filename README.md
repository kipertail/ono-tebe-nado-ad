# Оно тебе надо

Учебная проектная работа Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

## О проекте

Страница свёрстана по макету Figma для экрана шириной от 1100 px. Использованы семантическая HTML-разметка, CSS Grid и Flexbox, локальные шрифты Raleway и изображения из заготовки проекта. Список лотов поддерживает перенос дополнительных карточек на новую строку.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.
